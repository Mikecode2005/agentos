# AgentOS V0.4 — Permissions, LLM teams, terminal, dashboard

## Permissions & sandbox

```bash
agentos permissions init
agentos permissions show
```

Policy: `.agentos/permissions.json` — roles, path allow/deny, blocked commands, network toggle.

## Terminal

```bash
agentos terminal "ls -la src"
agentos terminal "npm test" --role tester
```

## LLM-backed team plans

```bash
export OPENAI_API_KEY=sk-...
# or ANTHROPIC_API_KEY / AGENTOS_LLM_PROVIDER + AGENTOS_LLM_API_KEY
agentos team run software-team "reduce auth DB load"
```

Without a key → deterministic stub plan.

## Optional transformers.js embeddings

```bash
npm install @xenova/transformers
export AGENTOS_EMBEDDINGS=transformers
```

## Dashboard

```bash
agentos dashboard
agentos dashboard --port 3847
# http://127.0.0.1:3847
```
