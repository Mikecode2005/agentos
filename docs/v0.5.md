# AgentOS V0.5 — Real execution loop

## Team steps run real tools
- researcher → memory.search / memory.why / list_dir
- coder → read_file / list_dir / memory.add
- tester → sandboxed terminal (npm test)
- reviewer → memory + optional LLM review
- deployer → git status via terminal

All under role permissions and path/command sandbox.

## Filesystem tools
`read_file`, `write_file`, `list_dir` gated by `checkPathAccess`.

## Audit log
`.agentos/audit.jsonl` for every tool invoke.

## Memory MCP (stdio)
```bash
agentos mcp
# {"id":1,"method":"memory.search","params":{"query":"redis"}}
```

## Skills applied
Team steps call `matchSkills`. CLI: `agentos skill apply "debug auth"`.

## Memory update
`store.update(id, patch)` rewrites JSONL and refreshes embedding.
